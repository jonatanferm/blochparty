# J coupling and bright fat

`jcoupling_fat.py` asks whether J coupling explains bright fat at 3 T: the triglyceride fragment model (`blochparty.jcoupling`) against fat T2 measured with spin-echo trains of different echo spacing. The finding is in the script's docstring and in `docs/lessons/reference-data.md`.

    uv run python validation/jcoupling/jcoupling_fat.py
